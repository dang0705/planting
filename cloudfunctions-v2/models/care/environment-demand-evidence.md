# 光照与 VPD 联合干燥需求：依据与接入条件

归属 E04／E06 原票 `z8v0kmr973`。当前接入点是已有 `DryingInterval.environmentDemand`：它接受单位参考日的需求区间，现有用例完成时间积分、窗口与盆土安全判断。光照／VPD 到这个需求的映射尚未获准，不能用任意倍率填满接口。本文不新增运行参数、发布策略或用户输入。

## 已确定的计算边界

1. 有效室内实测优先；否则由和风室外温湿度经获准室内模型估算。太阳辐射由 Open-Meteo 提供。室外 VPD 不能直接替代室内 VPD，空气 VPD 也不能无依据替代叶片与空气间的水汽压差。
2. [Oren 等（1999）](https://onlinelibrary.wiley.com/doi/10.1046/j.1365-3040.1999.00513.x)研究的是气孔导度对水汽压差的响应。其原式 `gs = gsref − m × ln(D)` 中，`m` 是带导度单位的敏感度；若写成 `gsref × (1 − s × ln(D / Dref))`，才有无量纲 `s = m / gsref`。论文的统计斜率不能当作所有植物的固定耗水倍率，导度也不能直接当作整盆失水速率。
3. [Grossiord 等（2020）](https://www.pnnl.gov/publications/plant-responses-rising-vapor-pressure-deficit)支持高 VPD 下气孔导度降低、蒸腾响应存在植物及条件差异。因此不能要求 VPD 越高，下一次检查必定越早；也不能把气孔关闭作为整盆失水为零的条件。
4. [FAO-56 第七章](https://www.fao.org/4/x0490e/x0490e0c.htm)将植物蒸腾与土壤蒸发分开处理。这里采用其区分原则，不把农田作物系数移植为室内盆栽参数。盆壁、基质与植物影响可以由经验证的整盆经验响应共同表示，也可以分量表示；不得在环境需求与保水修正中重复计算同一影响。
5. 联合响应须先作用于同刻、同位置的输入，再按实际时长归约需求。DLI 保留日总光量职责；非线性时序响应不能由分别平均后的光照和 VPD 冒充。输入区间经过非单调响应时还须检查区间内部极值，不能沿用 VPD 点值公式的单调端点传播结论。

## 原始数据资格

[Wall 等：Essex 原作者数据仓](https://researchdata.essex.ac.uk/248/)公开了甘蔗／豇豆气体交换与 PlantArray 整株蒸腾数据，许可为 CC BY 4.0。本次核验的是页面提供的 Excel 归档，不是根据论文标题推定字段存在。

| 实际文件 | 可证明的内容 | 不能用于联合需求标定的缺口 |
|---|---|---|
| `Ditech-system_Transpiration_Scale 1.xlsx` | 261 个相对时刻，0～780 分钟，间隔 3 分钟；两列日别蒸腾值 | 缺同刻光照、温湿度／VPD；`Transpiration_rate_g` 未写清速率的时间分母；本表未提供完整日期和时区 |
| `Figure 5.xlsx` | Ditech 与 APS 的日内蒸腾率及标准差比较 | 均值与标准差不能还原逐盆观测；缺同刻环境与明确单位 |
| `Diurnal_APS_Sugarcane.xlsx` | 叶片尺度的导度、光合作用与蒸腾，带时间及单位 | 叶片结果不能替代整盆失水；无同刻温湿度／VPD |
| `Licor-APS data 24-25-27th Aug.xlsx` | 有 `6800_Qin` 光照字段 | 属于另一组叶片仪器比较，不能按行号或“同为白天”拼接 PlantArray 记录 |

结论：该归档可保留为仪器与尺度资料，**不准入光照／VPD 联合响应拟合、整盆干湿循环或实际水量换算**。元数据采集年份与覆盖期也存在不一致，不能据页面年份补造日期。此结论只适用于已下载版本；取得可配对的环境原始记录与方法后可重新核验。文件摘要、字段及时间步在 `environment-demand-data-qualification.json`；复核入口为 `scripts/inspect-wall-demand-data.py`，仅使用 Python 标准库读取归档，不运行 Excel 宏。

### 同盆同刻配对候选

[Sun等（2024）原论文](https://doi.org/10.1093/hr/uhae256)指定的[作者数据仓](https://github.com/suntingsd/System-mapping)提供环境、逐盆蒸腾与体积含水量工作簿。实际解析得到32品系、96个盆标识、4800个共同时间点，间隔3分钟；两格含水量缺失，完整配对460798条。这里的光照和VPD来自共享环境表，不能说每盆都有独立环境测量。

该数据具备同期结构，但尚不具备绝对量标定资格：工作簿及已检查作者脚本没有明确PAR、VPD、蒸腾的单位与归一化方式；没有时区、逐次灌溉、排水或原始盆重。实验使用陶瓷颗粒并覆膜抑制蒸发，不能作为开放盆整盆净失水。论文描述六天分析，文件覆盖十天，重复数表述亦不一致；不能替作者选择实验阶段。论文许可与仓库数据许可分别核验，当前不向仓库复制原始测量记录。数值大小不用于猜测单位，缺失格不补零。

该候选的文件摘要、字段、配对统计与准入缺口保存在 `environment-demand-paired-data.json`。复核命令为 `python3 cloudfunctions-v2/scripts/inspect-sun-demand-data.py <原始工作簿路径>`；工具只接受指定SHA，不联网、不执行宏、不拟合。它证明文件结构可配对，不能证明测量准确、环境因果关系或预测有效。不同品系与同一盆的相邻记录不得作为独立重复随机混入验证集。

原始文件的960组“同盆、同日”对比显示，日表数值与三分钟序列直接合计之比为0.1473～3.0225，中位数约0.9990。不存在能还原所有记录的统一倍率；不能凭中位数接近1就把每条记录解释为三分钟水量，也不能仅凭时间步长乘3就解释为每分钟速率。差异原因须由原始测量和处理说明解释，不能修改任一张原表使之相符。

原文Figure 1图轴仅标VWC、Transpiration和Time (Day)，没有补齐物理单位。[作者分析脚本](https://github.com/suntingsd/System-mapping/blob/main/game_debug/debug.R)选前六行日表，只证明分析取样范围，不能据此标记实际停水起点。其直接引用的[Pandey等方法](https://www.plant-ditech.com/wp-content/uploads/2024/10/Pandey-et-al_iScience.pdf)区分整株蒸腾与归一化蒸腾；方法中另一实验的灌溉安排不能移植到当前工作簿。该候选在测量字典、聚合处理和供排水阶段明确之前，停止进入参数拟合；无需继续重复检索同一图文。

## 可执行接续

后台采样继续复用 `substrate-water-evidence.md` 的同盆称重与根区依据，不另建采样体系。为验证联合需求，在相同样本与时段同时保留植物位置光照、室内温湿度，以及浇入、排出、移动或其他质量变化记录。必须先明确观测是叶片蒸腾、整株蒸腾还是整盆净失水；三者不能直接互换。

合格数据到位后，先锁定植物／基质／盆器及环境适用范围，再按完整植物或完整循环划分拟合与独立验证，不能随机拆分相邻时间点制造独立性。候选响应需与固定需求对照，核验高 VPD、光照变化、根区供水及缺段条件。完成参考条件归一与版本裁决后，才生成现有 `DryingInterval` 并驱动“当前盆土状态 → 剩余窗口 → 提前检查”的同轮回放。

当前研究候选尚不能支撑数值标定，不继续增加倍率包装函数，也不因候选数量增加而发布策略。恢复该候选的条件是取得原始测量字典、日内到日表的处理说明及完整供排水阶段；另可由条件明确的盆栽配对数据接续，不以反复检索同一公开文件替代数据取得。普通盆栽的适用性仍需同盆水分与环境证据验证，不能由覆膜豇豆实验直接授权。保留现有数学与安全判断能力，正式响应、真实植物非零剩余时间和实际施水量分别保持未验收。MVP 不因此增加专业用户输入。
