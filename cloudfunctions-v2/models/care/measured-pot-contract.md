# 实测盆器几何合同

归属：E04 原票 `z8v0kmr973`。本增量接通圆形内盆尺寸与既有盆器安全门，不新增 HTTP 路由、运营参数或正式保水策略。

输入保持盆口内直径、盆底内直径、内深三项厘米尺寸。必须确认尺寸来自实际种植内盆，装饰外盆不满足条件。三项均为有限正数；缺失明确为 `null`，不猜测盆高，不用单项直径填补另一项，不把字符串转换成数值。圆台近似适用于圆形且侧壁线性变化的容器；不代表任意异形盆的实测容积。

独立数学依据：圆台体积 `V = π × h × (R² + R×r + r²) / 3`，输入直径先除以二得到内半径。等径自然成为圆柱。单位定义 `1 cm³ = 1 mL`、`1000 mL = 1 L`。这些是固定数学及单位规则，不是可发布的经验配置。

三项齐备且实际内盆确认才输出几何容积；否则几何量缺失，安全状态为缺证据。排水不可用输出排水风险，排水未知保留缺证据。非法尺寸、非法布尔证据和计算上溢或下溢必须拒绝。安全门的 `safe` 只表示本次盆器证据条件满足，不是浇水许可。

容器体积不等于基质填充体积，更不等于可用持水量。缺少填充高度、基质物性与根系占用等证据时，`substrateVolumeMl`、`waterRetention` 明确为空。旧版尺寸推测及材料、基质倍率不进入此合同。

验证层次：`unit_fake`，真实经过尺寸计算和安全函数，不替换计算边界；独立 Expected 使用上述数学公式、单位定义和批准计划第六节的证据边界。未验证实际盆器测量、DMN 引擎行为、正式发布、数据库或 CloudBase HTTP。
