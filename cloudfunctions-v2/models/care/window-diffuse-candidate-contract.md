# DHI 窗外散射实验基准

归属 E04 原票 `z8v0kmr973`；用户要求优先补散射及室内衰减链路。本增量实现真实 Open-Meteo DHI 时段归一化到窗外接收平面的实验回放，不改变正式算法发布状态，不新增依赖、Provider 默认策略或 HTTP 入口。

依据：[pvlib 官方均匀天空模型说明](https://pvlib-python.readthedocs.io/en/v0.16.1/reference/generated/pvlib.irradiance.isotropic.html)。公式为 `窗外天空散射 = DHI × (1 + cos(窗面相对水平倾角)) / 2`。天空亮度均匀、完整无遮挡天空是显式假设，不是现场确认事实；不含地面反射。0°朝上平面接收 DHI，90°竖窗接收 DHI/2，180°朝下不接收该模型的天空贡献。竖窗的一半来自该特定球面投影，不能泛化成室内固定折扣。

调用者必须显式选择 `skyModel = isotropic`，不能默认启用。它是独立离线候选，不是已经发布的天空模型。DHI 使用 W/m²，倾角使用度；缺值保持 null，有效零保持零，非法值拒绝。输入与输出保留窗外平面引用。这个均匀天空公式不需要太阳入射角；其他非均匀天空模型可能需要太阳方向等输入，不在本增量中默认切换。

回放经过已有 Provider 归一化，保留每个真实区间、前一时段均值、来源与时区，不补齐全天，不混用瞬时量。本公式在固定平面与均匀天空假设下对 DHI 线性，因此可消费相同时间语义的区间均值；不能由此推断实际天空分布及遮挡随时间不变。

明确未完成：外遮挡与方向加权天空视域、玻璃、窗帘、窗口有限孔径、植物位置散射传播、现场误差界限、PPFD/DLI 合并。`productionAdmission=false`；输出名为无外遮挡的窗外散射估计，不声称这是植物实际获得光照，亦不是实际非均匀天空条件下的严格上下界。

独立 Expected 来自上述官方数学公式及水平、竖直、向下平面解析边界。`unit_fake` 验证物理公式与非法输入；`unit_real_data` 验证已保存真实 Provider 制品经过实际归一化和计算，无计算模块替身。将所有倾角错误设成一半必须导致独立用例失败。真实制品回放不证明现场光照、完整室内衰减或 CloudBase HTTP。
