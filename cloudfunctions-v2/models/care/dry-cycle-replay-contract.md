# 历史干湿循环残差回放合同

归属：E04 原票 `z8v0kmr973`。依据批准计划第四、六节，先回放比较，正式个体校准仍须策略发布。本增量不新增运营配置、HTTP 路由、默认倍率或持久化写入。

输入来自同一个已完成历史循环：实际浇水起点、未加入个体校准的历史预测目标窗口、可靠观察的相同目标状态窗口，以及回放时刻。窗口为 UTC 整数毫秒，最早不晚于最晚，允许点值。缺失明确为 `null`，不是零时刻。输入提供者必须核验循环与目标状态一致；本纯用例不承担数据库归属核验，也不能证明调用者提供的布尔断言真实。

证据准入要求：循环已完成且观察可靠；盆器、基质、位置条件一致；历史预测版本兼容；预测明确未加入个体校准。任何条件为假或未知，不计算残差。观察窗口尚未结束时不能作为历史反馈。预测或观察早于该实际浇水、窗口倒序、非法时间和脏类型拒绝。该用例不把表土照片等价为可靠根区干燥，不自由设置可信度或样本数量阈值。

独立区间算术：`残差下界 = 观察最早 - 预测最晚`，`残差上界 = 观察最晚 - 预测最早`；毫秒除以 1000 变为秒。正值表示实际达到目标较晚，负值表示较早，跨零保留方向不确定性。该区间差保守保留端点，不取中值，不计算乘数。

没有已发布个体校准策略时，可输出符合上述证据条件的离线残差，但 `calibrationEligible = false`。策略与证据均满足只表示可供后续受控校准；`personalCalibration` 始终为空。旧 DMN 中正式校准入口的策略准入仍有效，本回放不冒充其引擎执行或自动改变线上模型。

验证层次：`unit_fake`，经过真实回放及准入函数，无替身。Expected 来自批准计划边界与独立区间差手算。未验证真实循环采集、MySQL 归属或版本读取、DMN 行为、样本充分性、拟合、策略发布及 HTTP 闭环。
