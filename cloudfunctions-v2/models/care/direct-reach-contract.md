# 植物位置直射可达性内部合同

状态：E04 离线几何，不是正式养护建议；归属原票 `z8v0kmr973`。

把植物位置向太阳方向反向追踪，求与竖直窗口平面的交点，再检查交点是否在实际透光开口内。依据为 [PBRT 射线定义](https://www.pbr-book.org/4ed/Geometry_and_Transformations/Rays) 与 [射线和平面求交](https://www.pbr-book.org/3ed-2018/Shapes/Disks)；下列窗口坐标与判断是本项目的明确几何约定。

窗口平面是竖直平面。坐标原点由上游明确提供，横向 x 是从室内朝外看窗口时向右，纵向 y 朝上。植物输入横向 x、高度 y 和到窗口平面的垂直距离，单位均为米；距离严格为正，不把斜向距离或“近窗”档位当作准确测量。太阳高度及真北顺时针方位沿用窗面直射合同。

每个实际透光矩形有独立引用与左、右、下、上边界。连窗中间的墙体不计入透光开口；多个矩形取并集，不能把它们的整体包围盒当成一块玻璃。

```text
δ = 太阳方位角 − 窗面外法线方位角，归一至 [−180°, 180°)
x_hit = plant_x + distance × tan(δ)
y_hit = plant_y + distance × tan(太阳高度角) / cos(δ)
```

太阳在地平线或以下时返回 `below_horizon`。太阳从背面或平行于窗面来光（|δ| ≥ 90°，或太阳高度为90°）返回 `no_forward_ray`。其余情况保留交点：在任一矩形严格内部为 `reachable`；只落在边界为 `boundary`；均未命中为 `outside_apertures`。结果引用排序稳定。边界不自动当成已确定的可达直射，不增加人为容差或默认窗框厚度。

输入坐标必须有限，矩形有正面积、引用唯一且非空；缺窗口几何、非正距离或不可表示的计算结果以固定中文错误拒绝。计算不改输入，不读 Provider 或数据库。

此结果仅说明给定几何下的一条无遮挡太阳射线是否通过透光开口，不证明玻璃透过率、外部建筑、室内物体或植物叶片未挡光，也不提供离窗距离平方衰减。实测／估算来源和几何误差区间由快照与后续传播准入处理；不得把单点离线计算伪装成视觉测量或全天结论。非竖窗暂不适用此用例。
