# 同盆根区水分、剩余过程与净补水

E04 原票 `z8v0kmr973`。本增量只在离线实验接通当前定量根区状态与已实现非线性环境需求，不新增生产默认值、数据库或用户输入。真实参数准入、实际施水量和 HTTP 建议仍待验收。

## 共同参考与单位

[明尼苏达大学推广资料](https://extension.umn.edu/natural-resources/conservation/agricultural-soil-and-water/irrigation/soil-moisture-sensors-for-irrigation-scheduling)给出体积含水率（水体积／基质体积）及缺水量定义。这里只采用量纲关系，不继承农田阈值。有效基质体积 V 以毫升计，当前体积含水率 c、检查干燥阈值 t、补水目标 r 均为0～1分数，并有同一根区的依据。t 和 r 含义不同，不能把剩余失水量当净补水缺口。

```text
到检查阈值还需失水 S = V × max(0, c − t)                [mL]
补至目标的净缺口 N = V × max(0, r − c)                  [mL]
历史参考尺度 R = 同盆实测净失水 M / 同期归一需求积分 A    [mL/参考干燥单位]
观察时刻的剩余干燥单位 U = S / R
```

A 必须从同盆历史环境按**同一响应参数组**逐时算出，按实际时长积分；不能直接用过去几天的自然天数代替。R 是该盆在已声明参考响应下的失水尺度，不是“这盆每天必定蒸发这么多”。它只用当前观察之前的数据，未来天气或预测输出不得反哺 R。

参考已经包含该盆器、基质和个体的效果，下游保水倍率与个体倍率均须显式为1；出现其他值拒绝，不重复修正。此实验不准许换盆、改变基质或位置后沿用参考；植物位置与栽培版本必须一致，必须确认校准期间没有未计入的浇入、排出、移动或其他质量变化。净失水以有依据的毫升值输入，不把克直接默认为毫升。

范围采用保守相反端点：S下端=V下端×max(0,c下端−t上端)，上端相反；R下端=M下端/A上端、上端相反；U下端=S下端/R上端、上端相反。非负量可为有效零，参考 M、A 必须有严格正下端。相关性可能使包络变宽，不能称作置信区间或声称所有组合同时出现。

## 证据与失败边界

- 本组合只接受明确的 `synthetic_experimental` 样本。日期和净缺口必须使用同一份观察；本次限定观察时刻等于计算时刻，避免用旧水分值冒充当前水量。
- 有效基质体积不等于几何盆容积；根区证据不等于表土照片。缺失对应输入保持缺证据，不能从材料标签生成含水率。
- 历史校准必须完整连续覆盖，结束不晚于观察；未归因的水量变化、未来泄漏或同盆/版本不匹配拒绝。历史合法缺段或参考尺度不可求时仅阻断时间换算，不抹掉独立有效的净缺口。
- 缺补水目标时可以保留日期；缺检查阈值时可以保留净缺口。净缺口仍不等于实际施水量，`appliedAmountMl` 继续为空。
- 检查干燥阈值区间完全高于补水目标区间时，条件互相矛盾并拒绝计算；区间重叠本身不证明次序矛盾，也不授予生产参数资格。
- 原始固定植物基线完整保留在输入快照，但不把它未经换算套入本次同盆体积尺度。本分支由当前根区观察推导剩余量；失败时不复用调用方预填的剩余单位或旧日期。
- 盆土安全门继续独立生效：偏湿可暂停实际浇水，即使存在正净缺口也不授权浇水。已知实际浇水事实照常保留，观察不重置或补造历史。
