# 同盆净补水与实际浇入量的离线换算

E04 原票 `z8v0kmr973`；只处理用户授权的合成样本。生产策略、公开接口及用户输入不变。本合同不批准任何容积比例、留水比例或安全上限。

## 水量语义

[FAO 灌溉效率说明](https://www.fao.org/4/T7202E/t7202e08.htm)区分浇入水量与最终留在根区的有效水量；[净量转总量说明](https://www.fao.org/4/U5835E/u5835e04.htm)使用净量除以效率。这里仅采用水量守恒关系，不采用农田灌溉系统的效率数值。家庭盆栽的比例必须有自己的方法、流速、基质、起始水分和排水条件依据。

在明确的单次供水及排水观察区间内，净留水量 = 实际浇入量 × 净留水比例。比例包含该区间已核对的供水损失及排出，不能再次加同一份排水损失，也不等于栽培保水倍率。超出标定方法、状态或施水量范围不可外推。单次操作期间的蒸散及其他水量变化须已经计入参考比例，不能用未知水量余额推导。

若根区缺口 N=[Nmin,Nmax]、净留水比例 e=[emin,emax]，可能需要的施水量包络为：

```text
可能需求包络 = [Nmin / emax, Nmax / emin]
```

这只是可能结果的范围，不是“随便选一个都足够且安全”。另需同一观察对应的、明确允许留在根区的补水区间 [L,U]。它不能由 N 自动复制得到。L 是本次可接受的最低补水，U 是本次允许的最高净留水；两者的证据必须明确。

```text
同时满足最少补水和最多净留水的范围 = [L / emin, U / emax]
候选施水范围 = 上述范围 ∩ 已核验施水量适用域 ∩ [0, 单次安全上限]
```

这个交集里的每一个量都满足已声明的允许净补水范围。与安全上限取交集可以保留有效子集；不能裁剪“可能需求包络”并声称完成补水。交集为空或只能取零时，不给单次施水候选，不自行决定分次次数、间隔或补足策略。各区间的端点按保守组合处理，不是统计置信区间；它们不能证明真实植物的安全性。

## 准入与失败

- 数值计算限有限、非负有序毫升区间；净留水比例为严格正、上限不超过1的区间。缺值保持缺失，正数溢出或下溢不伪装为零。
- 根区净缺口为零时不因其他输入建议浇水；缺允许净留水范围、比例、适用域或上限时不补默认。
- 组合用例复用当前根区样本及既有盆土安全门。只有本次判断为 `water_allowed`，且实际内盆自由排水已确认，才可给离线施水候选；湿土、未知/过期/表土证据和排水风险不能被正缺口覆盖。
- 净留水参考须属于相同植物位置、栽培版本和供水方法；允许净补水范围须对应同一当前根区观察。参考核验时间不晚于当前观察，水量平衡已核对。换盆、改变方法或无法确认来源时拒绝沿用。
- 若定量观察全部高于检查干燥阈值，却宣称“已可靠达到该阈值”，属于同一观察中的冲突，不能给施水候选。
- 整体结果始终为 `synthetic_experimental`、`productionAdmission:false`。`appliedAmountCandidateMl` 仅为离线候选；原有净缺口结果中的 `appliedAmountMl` 仍为空。不会创建事实、计划、提醒，也不改变未知历史或重置干燥进度。
