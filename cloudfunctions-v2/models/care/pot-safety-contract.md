# 实际种植盆器安全条件

本合同承接已批准整体计划第六节：装饰外盆不能替代实际内盆，尺寸缺失或非法不能形成有效几何，排水事实不得填默认值。对应票据为 E04/E06 `z8v0kmr973`。

输入是上游已归约的三项证据：`actualInnerPotConfirmed`（已确认实际内盆）、`potGeometryValid`（几何证据有效）、`drainageAvailable`（排水通道有效）。每项只能是 `true`、`false` 或 `null`；`null` 表示未知。非法类型拒绝，不能按 JavaScript 真值强制转换。

判定顺序：

1. 实际内盆未确认，或几何不有效：`insufficient_evidence`。
2. 上述两项成立且排水明确无效：`drainage_risk`。
3. 上述两项成立且排水未知：`insufficient_evidence`。
4. 三项均成立：`safe`。

`safe` 只表示这三项盆器安全条件成立，不表示可以浇水、不证明根区干燥、也不证明基质及保水倍率可用。未确认内盆时不能用外盆的排水证据形成实际内盆风险结论。

这些判定是不可配置的证据准入规则，不引入倍率、尺寸阈值或保水默认策略。尺寸计算及证据有效性由独立上游负责；本用例不重新计算体积，不生成建议、事实或计划。

`pot.dmn` 中 `pot_decision_pot_safety` 保存相同五条互斥决策行。TypeScript 用例是当前离线可执行载体；测试经过真实函数且没有替身。对应全部三值组合为 27 种。DMN 文件的兼容引擎执行和 Modeler 保存再打开仍待验收，不能由这些 TypeScript 测试代替。
