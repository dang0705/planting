# 有限窗洞到植物位置的散射候选

## 输入和范围

这是 E04 的离线计算，明确选择均匀天空（isotropic sky）。使用实际竖直透光开口、植物坐标和正的垂直离窗距离；接收面穿过植物目标点、平行于窗面并朝窗。它不是叶面，也不代表整株平均光照。

开口沿用直射几何合同。多个矩形取并集，不重复计入重叠，也不将连窗中间的墙体当作透光区域。窗口低于植物高度的方向不属于天空，首版不计算地面反射。

## 公式和依据

辐照度是各入射方向的辐射亮度乘接收余弦，再对立体角积分。面积转立体角还要乘开口面余弦并除以射线长度平方。依据：[Physically Based Rendering，辐射积分](https://www.pbr-book.org/3ed-2018/Color_and_Radiometry/Working_with_Radiometric_Integrals)。

设 x、y 是相对植物的窗洞坐标，d 是垂直离窗距离。均匀天空辐射亮度为 DHI/π；两个平行面的余弦均为 d/射线长度。因此：

```text
天空几何系数 F = 对实际可见开口积分：d² / [π(d²+x²+y²)²] dx dy
目标窗平行面散射 = DHI × F
```

这一步直接积分开口所占的余弦加权立体角；不先乘窗外二分之一再加任意距离折扣。

令 X=x/d、Y=y/d，矩形解析积分原函数为：

```text
G(X,Y) = [X/√(1+X²) × atan(Y/√(1+X²))
          + Y/√(1+Y²) × atan(X/√(1+Y²))] / (2π)
矩形 F = G(右,上) − G(左,上) − G(右,下) + G(左,下)
```

对 G 分别求 X、Y 导数可还原 1/[π(1+X²+Y²)²]。全无限竖窗上半平面的积分为二分之一，有限天空开口的模型系数范围为零至二分之一。单位解析场景 X∈[-1,1]、Y∈[0,1] 的独立 Expected 是 √2/π × atan(1/√2)。

实现按横向边界分条，合并每条纵向区间后积分，以保留矩形并集。使用浮点解析求值，极小或极远开口仍可能产生消去误差；不声称认证数值误差范围，超出理论范围时拒绝而非钳制。

## 尚未覆盖

均匀天空是明确实验假设，并非现场事实。当前未计算外部建筑遮挡、玻璃、窗帘、室内其他遮挡、反射增强、非均匀天空和叶面方向。这些缺口不能通过虚构透光率、经验天空视域因子或默认位置补齐。

结果始终标为候选，productionAdmission=false。理论系数范围不是现场误差上下界。缺 DHI 返回 null；有效零返回零。真实 Provider 时段均值可在线性固定几何模型中逐段消费，但不据此伪造完整全天数据或正式 DLI。

## 验证

18 条 TypeScript 用例覆盖解析基准、天空地平线限制、几何同比例不变、距离与横向位置、开口分割和重叠、中间墙体、输入合法性、缺值及真实 24 条气象区间。移除地平线裁剪的受控突变使相关用例失败；恢复后全量后端测试通过。构造的窗口不证明真实现场几何；未验证 HTTP 或正式发布模型。
