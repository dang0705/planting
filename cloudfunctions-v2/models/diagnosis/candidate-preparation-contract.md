# 诊断知识候选审核准备

本用例属于 E05 原票 `z8v0kmrg8a`。接线方提供冻结的完整候选 v1 与关系索引 v1 Schema，并提供独立核验题包发布状态、来源许可及适用性的读取接口；请求和候选正文不能自报 Schema 或“已验证依赖”。本增量不新增可配置阈值或默认发布引用。

执行路径：纯 JSON 内容锁定 → 完整候选结构校验 → 冻结快照 → 一次读取精确题包及来源主张修订 → 关系索引结构校验 → 引用闭合 → 完整正文摘要 → 返回待审核内容。

- `prepared_for_review` 仅表示可以继续审核，不表示人工审核、条件语义、植物适用性或知识发布准入已经通过。
- 来源主张按来源代码、主张代码和修订号去重；不同修订不能合并或自动替换为最新版本。
- 原数组顺序及所有候选字段参与摘要；不从 SQL 关系列重组正文。
- 异步读取开始前固定内容，后续调用方修改原对象不改变该次快照；返回内容递归冻结。
- 结构非法不读取外部依赖；未发布题包、缺来源主张或闭合失败拒绝准备。
- 来源读取异常交给受控上层处理，不转成成功。内部错误路径、知识代码与候选正文不能原样进入公开诊断响应。
- 不调用 AI、不生成处置、不写审核或发布记录，不写养护事实、计划及提醒。

当前验证使用真实冻结 Schema 和真实领域校验器；题包/来源读取使用替身。真实 Repository、CMS 审核与发布事务、HTTP 及内容审核仍需后续验收，不能由这些测试替代。
