# 首版诊断题包复用

本范围属于 E05 原票 `z8v0kmrg8a`。V2 首版只复用 V1 的黄叶、萎蔫和虫害题包，不扩展其他模式，不复用 V1 用户会话或诊断结果。题目内容是可复用主数据，与用户业务记录分开。

`questions.json` 保留当前源码中的完整题目、选项、主题、复合题元数据和虫害安全提示；`manifest.json` 记录精确来源及文件摘要。它们是来源内容快照，尚不是 CMS 审核通过或可用于正式诊断的发布版本。更新制品须核验内容差异，不能在运行时自动跟随旧源码。

离线生成使用 `node scripts/backend-v2/capture-v1-question-packages.mjs`；加 `--check` 只核验能否从记录的来源重建相同内容，不改文件。脚本不进入运行包，也不属于每小时同步自动化的允许命令。

- 黄叶固定包为四题；萎蔫固定包为六题，以当前 V1 内容为依据。
- 虫害保留八类及十四条题目素材，运行时仍按候选和已有证据选择题目，不能一次展示整个素材库。
- V1 虫害分档题数为低可信三题、中可信二题、高可信及较可信一题、直判零题；此处只保留来源策略，不代表 V2 已发布这些阈值或选择算法。
- 不引入根腐、百科扩种或新的病虫害题包。

V2 的 `validateV1PackageAnswerMembership` 只接受应用层从服务端会话取出的题包快照作为授权源。客户端回传题包不参与授权；首次完整提交必须为 `answer_submit`，题目完整且不重复，选项必须属于锁定快照。题数按各版本快照核对，不套用全局四题规则。零题虫害不可提交答案，应由已准入的直判用例处理。

时间线题额外允许服务端明确声明的 `care_behavior_timeline` 选项。选择时间线或“已填写空气环境”仅形成后续证据验证要求，不证明证据存在或有效，更不产生养护事实。成员校验不能替代归属、复合证据、有效期、人工审核、发布、题包生成与诊断归约。

当前已实现制品固化和成员校验；题包锁定持久化、复合答案校验、虫害选题、受控发布及真实 HTTP 仍待接线。运行代码不依赖或导入旧 `cloudfunctions/**` 模块。
