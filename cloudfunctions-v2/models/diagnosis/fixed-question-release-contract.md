# 固定题包发布与长期会话创建

复用现有 `business_policy_releases` 与 `active_business_policy_releases`，领域为 `diagnosis`、策略代码为 `fixed_question_packages`，结构版本为 `diagnosis-fixed-question-packages/v1`。不创建第二套发布表。

正文只包含结构版本、来源引用及其 SHA-256、黄叶和萎蔫两组完整题目。虫害仍属于允许范围，但动态选题有独立流程，不能伪装成固定包。本合同不发布虫害轮次、评分或治疗知识。

可运行版本必须同时满足：发布行与活动指针唯一且范围一致；技术兼容字段为空；版本、引用和摘要有效；正文经过严格顶层结构校验；每组题目能形成合法服务端题包；规范化正文摘要与发布行及指针一致；状态为 active；验证时间有效且不晚于生效时间；捕获时间处于生效区间。草稿、缺发布、未生效、过期、指针不一致或内容损坏均不得创建会话。数据库错误不伪装成不存在。

一次创建在同一事务中读取并锁定活动指针及发布行、选择症状对应题目、核验用户植物归属、生成服务端高熵会话引用、追加不可变快照并在原事务读回。历史会话继续读自己的快照，不能因 active 切换而重建或覆盖。无回退到本地文件的默认路径。

本地源制品仍是未发布内容，用户确认的 V1 复用范围不冒充线上 active 发布。测试只在隔离 MySQL 中构造发布制品，不能作为 CMS 或生产发布验收。创建用例本轮只提供事务内能力，公开创建路由须另外接共享幂等后才能开放。
