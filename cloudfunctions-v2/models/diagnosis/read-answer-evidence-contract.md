# 已保存答案的诊断输入读取

E05 原票 z8v0kmr974。复用首次整包答案的原子保存合同和现有题包快照，不新增表、配置或 HTTP。读取由已认证统一用户、用户植物和会话引用定位；原 Repository 的三项归属及有效用户/植物检查仍适用。active、completed 会话允许读回；failed、expired 不作为新计算输入。

同一短事务锁定原题包并读回全部答案、原答案引用和作答时间。只接受 diagnosis-answer-evidence/v1 完整正文：每题归属锁定题包、选项合法、复合证据完整、题包摘要相同，重新计算完整提交摘要，并逐题比较规范正文。缺题、额外题、重复题、重复答案引用、非法时间、坏正文或摘要错配均不得进入计算。没有答案返回 evidence_not_ready；零题虫害为 not_answerable，不能补成空答案计算。

输出按原题包顺序保存精确答案引用、作答时间和已验证正文，并携带原题包发布引用、内容摘要、提交摘要。输出复制后递归冻结，不覆盖数据库内容，不自动重新提交。用户申报仍是 answer 证据，空气来源申报不等于服务端实测，行为时间线不等于 care 已完成事实。该读取不创造 findingCode、病因、行动、最终结果或计划；后续归一仍须使用已审核映射。

本地隔离 MySQL 验证实际保存→新事务读取、归属拒绝和完整性拒绝。真实数据库不代表正式 HTTP、CMS 或模型已验收；数据库异常继续由事务设施回滚，不伪报 evidence_ready。
