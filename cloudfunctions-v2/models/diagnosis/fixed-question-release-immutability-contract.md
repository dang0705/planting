# 固定题包发布的数据库不可改写约束

适用范围仅为 `diagnosis/fixed_question_packages`。使用新的顺序迁移 020，不修改已经应用的 007。不改变其他领域策略，不执行生产迁移。

草稿可编辑或删除。发布达到 verified、active 或 retired 后，内部键、技术字段、公开引用、领域与策略代码、结构版本、版本号、正文、摘要、来源（属于正文）、验证时间、生效区间和创建时间均不可改写，且禁止删除。比较字符串时按字节，不能让数据库不区分大小写的排序规则绕过保护。

verified 可以激活或退役；active 可以退役；retired 可重新激活以支持回滚。已激活或退役发布不能退回 verified 或 draft 再改内容。允许按既有流程更新状态及更新时间，不允许伪装成另一领域策略绕开保护。已验证的其他策略也不能通过改领域或代码伪装成固定题包发布。

有新内容时追加新发布，再切换活动指针。历史会话继续持有自己的不可变题包快照。回滚业务版本时切换指针，不删旧发布、不改正文。

迁移没有字段搬运，执行前后发布与会话计数不变；验证包括保护字段拒绝、草稿编辑、激活/退役/回滚及其他领域不受影响。失败回退仅限尚未切换且获准的迁移环境中删除本迁移两个触发器；它会失去数据库保护，不能作为已验收正式运行状态。
