内部输入严格为 `{userRef, ephemeralCaseRef}`，两者为非空 ASCII 字母、数字、下划线或连字符，最多 64 字符，沿用存储引用容量。这里不新增 HTTP 路径或冻结公开引用前缀。身份从 identity 取得，客户端不得指定用户归属。

使用新连接和单条参数化 SELECT。统一用户必须 active，平台遗留 `_openid` 为空；案例必须同时匹配该用户内部键、精确区分大小写的案例引用及空 `_openid`。本人案例无论 active、completed、failed、expired 或 bound 都可返回 `owned`；截止时间不影响归属判断，防止在请求链前置阶段错误拒绝已完成绑定的历史重放。
