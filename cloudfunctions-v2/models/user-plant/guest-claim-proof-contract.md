# 游客认领：事务内持有证明准入

所属票据：E03 / z8v0kmr9mj。本增量依据已冻结的 `guest-session-claim/v1`，只完成认领事务的会话锁定与证明校验，不签发匿名主体、不创建认领命令、不授予用户植物归属。

输入由受控服务端适配提供：会话公开引用、经 CloudBase 验真的匿名主体 SHA-256 摘要、请求头中的原始持有证明、服务端 UTC 毫秒时刻、已发布的证明轮换宽限期（秒，0～300；没有发布快照为 null）。原始证明只在本次内存中使用，不进入 SQL、日志或结果。

先验证匿名主体摘要，再以常量时间比较持有证明 SHA-256。证明必须为规范的 base64url，解码至少32字节。不匹配、非法证明、错误匿名主体、失败会话统一拒绝；不能泄露存在性。有效期采用左闭右开：签发时刻可用，到期时刻拒绝。有效状态为 active/completed；expired 返回过期，failed 拒绝。

当前证明版本必须为1～4294967295整数。上一版只能返回当前版本减1，当前版本为1时不得存在上一版。上一版摘要与截止时间必须成对，截止时间大于签发时间且不超过会话到期时间。当前与上一版摘要不能相同。发布策略缺失或宽限期为0时只拒绝上一版，不阻断有效当前证明。上一版截止时刻拒绝。宽限期数值不重新延长已存截止时间；签发/轮换用例负责保证最多300秒，本增量不猜测轮换时刻。

Repository 只使用外部传入的真实事务，按精确会话引用和空技术 `_openid` 执行一条 `SELECT ... FOR UPDATE`。不自行提交、不写表、不创建会话或用户植物。成功仅返回已校验证明版本；不返回数据库键、摘要、原始证明或期限。缺记录统一拒绝；损坏存储数据返回不可用。后续完整认领事务继续锁定案例、核对登录用户、目标、命令及成功事实。

配置裁决：复用已确认 `identity.guest.proof_rotation_grace_seconds`；无新增默认、阈值或可配置项。没有真实匿名验真与策略发布接线时，本模块不构成公开认领能力。
