# 昵称与实测盆器档案应用合同

E03，票据 `z8v0kmr9mj`。这是既有用户植物档案编辑的内部应用切片，不是新增公开API，也不宣称完整档案完成。

沿用整体计划中的同事务幂等规则：受信调用方提供已认证用户、植物引用、旧版本、至少一项昵称或完整测量事实、已锁定策略引用与服务端时间；并提供经过主体隔离的共享幂等作用域及请求摘要。首次异步操作前冻结命令。请求摘要由调用方依冻结DTO生成，本层不新增摘要格式、保留时长或默认策略。

同一事务先取得幂等占位，再保存并读回档案，最后写完成收据。已完成的相同请求原样重放，跳过档案写入；请求摘要冲突或已有处理者也不能保存。首次成功收据采用同事务归属读回的严格UserPlantDto，保留原聚合身份、生命周期和UTC时间，并含公开档案事实。必须与本次新版本、昵称及测量事实一致；策略版本、内部主键、平台标识及原始JSON不得进入响应。

归属不存在返回404，旧版本冲突返回409，并将确定拒绝写为可重放收据。存储不可用、写入异常、读回异常、完成收据未确定均回滚，不留下已保存档案与处理中占位的半成品。

提交结果未知只能由新连接只读核对完整幂等作用域和请求摘要；已提交完成收据可原样返回，否则503，不重跑保存、不对旧连接回滚，不据此断言原事务未提交。普通内部异常由外层协议统一脱敏，本层不把错误原文转换成公开内容。

固定的HTTP状态和错误类别属于既有协议硬规则，不配置化。更新成功使用与单株GET相同的公开聚合合同；正式HTTP还需严格请求准入、身份/策略及正确作用域/摘要构造。当前已冻结档案字段不代表其余档案字段或完整度已完成。
