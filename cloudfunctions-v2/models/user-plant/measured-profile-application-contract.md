# 昵称与实测盆器档案应用合同

E03，票据 `z8v0kmr9mj`。这是既有用户植物档案编辑的内部应用切片，不是新增公开API，也不宣称完整档案完成。

沿用整体计划中的同事务幂等规则：受信调用方提供已认证用户、植物引用、旧版本、完整测量事实、昵称、已锁定策略引用与服务端时间；并提供经过主体隔离的共享幂等作用域及请求摘要。首次异步操作前冻结命令。请求摘要由调用方依冻结DTO生成，本层不新增摘要格式、保留时长或默认策略。

同一事务先取得幂等占位，再保存并读回档案，最后写完成收据。已完成的相同请求原样重放，跳过档案写入；请求摘要冲突或已有处理者也不能保存。首次成功内部响应仅含植物公开引用、新聚合版本、昵称及测量事实，不包含策略版本、内部主键、平台标识或时间。

归属不存在返回404，旧版本冲突返回409，并将确定拒绝写为可重放收据。存储不可用、写入异常、读回异常、完成收据未确定均回滚，不留下已保存档案与处理中占位的半成品。

提交结果未知只能由新连接只读核对完整幂等作用域和请求摘要；已提交完成收据可原样返回，否则503，不重跑保存、不对旧连接回滚，不据此断言原事务未提交。普通内部异常由外层协议统一脱敏，本层不把错误原文转换成公开内容。

固定的HTTP状态和错误类别属于既有协议硬规则，不配置化。内部响应尚不能替代完整 `UserPlantResponse`，正式HTTP入口必须另行完成严格DTO、身份认证、作用域/摘要构造与完整档案读回验收。
