# Unified BRV Fact Lifecycle Management

The project uses a cross-domain fact-condition mechanism that integrates documentation governance, maintenance validation, and session memory handling into a unified lifecycle flow.

## Evidence

- **maintenance**: Fact quality condition enforces manifest-scoped recall and lifecycle validation for all fact sources.
- **governance**: Dispatch task rules integrate BRV Recall Condition for subagent memory propagation.
- **validation**: Downgraded session memory is explicitly handled to distinguish superseded claims from active facts, maintaining the integrity of the fact condition.
