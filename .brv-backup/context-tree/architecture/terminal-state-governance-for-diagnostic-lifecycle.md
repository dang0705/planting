# Terminal State Governance for Diagnostic Lifecycle

The 'Yellow Leaf' diagnosis is strictly a 4-question terminal flow, deprecating all dynamic follow-up mechanisms across architecture, project management, and governance domains.

## Evidence

- **architecture**: Diagnosis shifted to a terminal 4-question package model; 'Yellow Leaf' mode is strictly a 4-question set governed by getQuestionPackageByMode.
- **project_management**: isQuestionPackageAnswerSubmitPayload enforces a 4-question minimum; planQuestionPackageState restricts non-package flows to single-question depth.
- **governance**: Leaf yellowing diagnosis is strictly constrained to a terminal 4-question route-package flow; dynamic follow-ups are officially deprecated.
