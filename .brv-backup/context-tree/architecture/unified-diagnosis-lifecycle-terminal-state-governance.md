# Unified Diagnosis Lifecycle & Terminal State Governance

The move to a terminal 4-question 'route-package' model is a project-wide architectural constraint that deprecates all legacy dynamic follow-up logic and iterative flows.

## Evidence

- **architecture**: Diagnosis system transitioned to a static, terminal 4-question package model (getQuestionPackageByMode); all dynamic follow-up mechanisms are deprecated.
- **docs**: System operates on a 'route' mode using a 'question package' chain, explicitly abandoning session follow-up patterns.
- **governance**: The system enforces a synchronized lifecycle for the diagnostic main-chain; leaf yellowing is strictly constrained to a terminal 4-question route-package flow.
