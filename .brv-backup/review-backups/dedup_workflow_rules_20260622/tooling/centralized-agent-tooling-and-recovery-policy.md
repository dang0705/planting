# Centralized Runtime Automator Recovery Policy

Technical recovery procedures for mini-program runtime automator are decoupled from product logic and must be consistently applied across both tooling infrastructure and agent dispatch governance.

## Evidence

- **tooling**: Defines shared recovery skills for transport failures, prioritizing diagnostic inspection of ports and WebSocket status over product-level error attribution.
- **governance**: Governs the injection of runtime automator policy context into subagent role packets to ensure consistent recovery behavior in dispatch tasks.
