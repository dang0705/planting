# P1 总 DDL 本地 MySQL 空库退出闸门

- 结论：`LOCAL_MYSQL_EMPTY_DATABASE_PASS`
- 证据等级：本地真实 MySQL 8.4.11；不是 CloudBase MySQL、不是公开 API、不是发布授权。
- DDL 版本：`backend-v2-schema/v1`
- 输入：`docs/backend-v2/schema/manifest.json` 所列 7 个按领域排序的 SQL 文件（`001 → 002 → 003 → 004 → 007 → 005 → 006`）。

## 环境

- 使用 Docker Desktop `29.8.0` 与官方 `mysql:8.4` 镜像，镜像摘要为 `sha256:85b9bf2e29cf836ecb8c2a15a935d4ba0c606631dff1dd79531a11983c638f2a`，实际服务端版本 `8.4.11`。
- 使用一次性容器、容器内临时数据文件系统且不映射宿主端口；未启动宿主 MySQL 常驻服务。
- 未连接、读取或修改 CloudBase。

## 负向约束

以下错误写入均被真实 MySQL 拒绝：

1. 用用户 2 给用户 1 的植物写档案，复合外键拒绝。
2. 把同一平台主体摘要绑定给另一统一用户，唯一约束拒绝。
3. 给同一游客植物案例写第二条成功认领投影，唯一约束拒绝。
4. 写入不满足 `发放=可用+预占+消费` 的 AI grant，检查约束拒绝。
5. 重放同一用户、产品动作和幂等键的 AI 预占，唯一约束拒绝。
6. 重放同一奖励 `event_id`，inbox 唯一约束拒绝。
7. 非法公开用户引用、大小写错误摘要、非法撤销时间和非法 nonce 摘要由 identity CHECK 拒绝。
8. `WCVP` 可作为登记来源写入，未知来源由分类 CHECK 拒绝。
9. 试用起算时间不等于用户创建时间、试用窗口不足 24 小时分别由复合外键和 CHECK 拒绝。
10. AI grant 缺失到期或到期不晚于发放、allocation 不守恒、兑换终态链接不一致、奖励收件终态字段不一致均被拒绝。

## 已证明与未证明

已证明：MySQL 8.4 语法、建表顺序、表/字段中文注释、字符集、外键、关键唯一约束、局部检查约束以及确定性空库重放。

未证明：CloudBase MySQL 的 DDL 兼容、权限规则、`_openid` 平台行为、真实事务隔离、并发锁/死锁重试、CloudBase SDK 读写、outbox/inbox 实际重放、公开 API 和发布切换。上述项目仍须在获得云端写入授权后于隔离 v2 环境执行，不得把本报告外推为 P1 全面退出。
