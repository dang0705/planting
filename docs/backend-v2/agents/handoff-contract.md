# Agent 交接合同

交接必须包含：ticket ID、ClickUp 当前状态及最后一次回写证据、计划角色名、当前运行时子代理名、输入 SHA、修改路径、Expected 来源、完成内容、测试命令和结果、真实环境限制、未覆盖内容、已知风险、下一步和最后一次 30 分钟心跳时间。

如果 ClickUp 状态仍为 `backlog`，交接不得写“已开始”；必须写明 `CLICKUP_BLOCKED`、失败原因和恢复条件。只有 ClickUp 与本地 tracker 状态一致，主代理才可以把交接纳入验收队列。需要环境或依赖恢复的任务进入 `blocked`，需要用户决策的任务进入 `human required`，产物齐全并等待验收的任务进入 `review needed`。

同范围缺陷合并为一次返工；第二次返工触发熔断，由主代理重新审查合同和输入，而不是继续堆补丁。
