# 后端测试矩阵

## 身份和归属

- 多平台登录、绑定、解绑、冲突和 session 失效。
- 用户 A 无法访问用户 B 的用户植物和小青上下文。
- 游客不能拥有用户植物、积分或会员。

## 植物身份和 CMS

- 科、属、种、亚种、变种、变型、杂交种、栽培品种、异名和 `spp.`。
- 父链冲突、来源缺失、重复 taxon key 和混合分类隔离。
- 百度候选不能越过审核。
- Qwen 禁止字段拒绝。
- 私有图片不能进入公共 release。
- CMS 发布失败不发贡献奖励。

## 用户植物、养护和诊断

- 暂未识别、候选待确认、已确认。
- 游客同会话认领、过期、跨用户、重复认领。
- 盆土 wet/moist/dry/uncertain、过期证据、湿土安全门。
- 光照、通风证据不足和室外风速误用。
- 建议、计划、提醒和事实边界。
- 固定黄叶/萎蔫题包和动态虫害题包。

## 积分和 AI 额度

- 同一行为只奖励一次。
- 暂不浇水和浇水检查同分。
- 兑换不降低等级。
- 同一等级只发一次 AI 奖励。
- CMS 全局主题只奖励一次。
- outbox/inbox 重放、宕机、乱序和并发。
- 多 grant 预占、结算、释放和到期。
