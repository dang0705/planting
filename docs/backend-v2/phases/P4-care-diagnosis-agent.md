# P4 养护、诊断与小青

范围：原子环境事实、不可变输入快照、派生环境指标、盆土视觉、浇水、施肥、光照、通风、黄叶/萎蔫题包、动态虫害题包、建议确认、计划、提醒、事实、小青工具和四类可奖励业务事件。

实施顺序固定为“先事实、后推导、再建议”：先完成原子环境事实的来源/范围/单位/时间/新鲜度校验和持久化，再冻结输入快照与派生环境指标，最后接入四类养护算法和诊断。不得从旧算法输出反推原子事实。

退出条件：原子环境事实不可被算法改写，派生环境指标可按输入快照与算法 release 回放；室外天气不得冒充室内实测；诊断不直接写事实，视觉不自动记录浇水，四类养护合同稳定，跨用户/跨植物访问被拒绝，奖励事件可重放且不重复。
