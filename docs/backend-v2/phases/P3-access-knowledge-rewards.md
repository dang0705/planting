# P3 访问、知识和奖励闭环

首版主链：游客或已登录用户主动临时识别/问诊/浇水 → 用户显式创建或绑定用户植物 → 同会话必要结果认领；百度候选 → 规范身份 → CMS 百科 → release；会员/试用/免费 → CapabilitySnapshot → AI grant。CMS 贡献 AI 奖励随扩种发布实验单独验收。目标态继续包含有效植物行为 → 积分 → 等级/兑换，但首版不运行此链。

首版退出条件：真实 HTTP 认领与会员/试用/AI 额度闭环；CMS 发布失败不发 AI 贡献奖；扩种奖励开放时多用户并发只发一次，免费用户可以使用 scope 匹配的有效奖励额度。积分/等级/兑换后续任务仍须满足各自独立的验收条件。

首版运行范围按[首版运行边界](first-release-scope.md)执行：会员/试用/AI 额度和用户植物认领进入首版；积分、等级和兑换的运行入口延后。已有奖励账本实现继续接受测试，但其存在不等于首版开放。CMS 贡献 AI 奖励只随审核发布的扩种实验单独验收。

已登录用户主动临时使用并随后绑定用户植物，依赖[已登录临时案例 P1 合同补充门](../contracts/authenticated-ephemeral-plant-case.md)；该门未过时不得复用游客证明或认领表伪装完成。
