# P0 产品决策与最短路径证伪

## 必须冻结

- 试用 AI 点数和能力范围。
- 免费用户植物数量。
- 积分兑换档位、能力范围和有效期口径。
- CMS 奖励主题键、全局获奖者和冲正边界。
- 分类权威源和冲突处理。
- CloudBase 匿名身份、Node 22、TypeScript 构建。
- 百度、和风、Qwen、支付、Storage 和 Agent 合同。
- outbox/inbox 丢失、重放、乱序和并发实验。

无法证明身份、额度、事件幂等、私图隔离、用户植物归属或 Qwen 禁区时，停止对应能力。

## Ticket 覆盖

- `TypeScript/Node22/CloudBase 构建证伪`：严格类型、CommonJS 构建、HTTP 云函数运行时、9000 端口、部署包与凭证边界。
- `植物分类权威来源与身份审计证伪`：代表分类层级、官方证据、冲突和隔离。
- `关键产品参数与成本边界冻结`：试用、免费植物数、奖励额度、积分兑换、EnvId、Storage、支付、保留期及性能/成本目标。
- `外部能力合同与可靠事件证伪`：游客、匿名身份、百度、和风、Qwen、支付、Storage、Agent、CMS 队列、MySQL、网关和 outbox/inbox。

四个 ticket 必须合计覆盖本文件“必须冻结”的全部项目；任何项目没有明确 `GO` 或 `STOP` 时，P0 不得退出。
