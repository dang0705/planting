## 组合模式

### 表单页

优先结构：

```vue
<uni-forms ref="formRef" :model="form" :rules="rules">
  <uni-group title="基础信息">
    <uni-forms-item label="名称" name="name">
      <uni-easyinput v-model="form.name" placeholder="请输入" />
    </uni-forms-item>
    <uni-forms-item label="类型" name="type">
      <uni-data-select v-model="form.type" :localdata="typeOptions" />
    </uni-forms-item>
  </uni-group>
</uni-forms>
```

### 列表页

优先结构：

```vue
<uni-search-bar v-model="keyword" @confirm="reload" />
<uni-list>
  <uni-list-item
    v-for="item in list"
    :key="item.id"
    :title="item.title"
    :note="item.note"
    showArrow
    clickable
    @click="open(item)"
  />
</uni-list>
<uni-load-more :status="loadStatus" />
```

### 可左滑列表

```vue
<uni-swipe-action>
  <uni-swipe-action-item
    v-for="item in list"
    :key="item.id"
    :right-options="rightOptions"
    @click="onSwipeAction(item, $event)"
  >
    <uni-list-item :title="item.title" :note="item.note" />
  </uni-swipe-action-item>
</uni-swipe-action>
```

### 弹层 / 抽屉

- 底部 sheet、居中 dialog、顶部 message：`uni-popup`
- 左右侧栏、筛选面板：`uni-drawer`

### 日期选择

- 月历/打点/签到/日期范围展示：`uni-calendar`
- 表单日期时间选择：`uni-datetime-picker`
- 日期文本显示：`uni-dateformat`
