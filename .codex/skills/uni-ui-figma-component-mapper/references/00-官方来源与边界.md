## 边界

- 本技能只负责“Figma 设计细节 → uni-ui 组件候选 → 代码骨架/实现护栏”的映射。
- 本技能不替代真实浏览器验收、微信开发者工具验收、视觉 diff 或人工设计评审。
- 若官方组件与设计稿不完全一致，优先标注“需自定义”，不要强行扭曲组件。
