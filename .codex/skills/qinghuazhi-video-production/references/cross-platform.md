# 跨平台共同策略

Evidence: Project + 多平台共同约束

## 默认共同母版

- 9:16 / 1080×1920。
- 20~35 秒优先 2~4 Scene、5~8 Shot。
- 前 3 秒至少给一个明确观看理由：痛点、反常识、结果预告或视觉冲突。
- “3 秒钩子”不是标题党，必须由后文兑现。
- 默认硬切，不为了炫技增加复杂转场。
- 有语音就有字幕。
- app 功能必须使用真实 `app_capture`。
- 产品展示前先建立用户问题，但不要拖到视频尾部才第一次出现青花植。
- 同一条母版不嵌入静态封面页；封面独立生成。
- 最终只保留一个核心 CTA。
