# 情绪、节奏、姿态与表达

Agent 只输出中文语义；Performance Mapper 负责翻译给 Azure Dragon HD Flash 和 Wan。

## rhythm

```text
紧凑  信息或动作事件密度较高，停顿短；适合钩子、冲突和快速推进
自然  默认，符合真实生活节奏
舒缓  动作事件更少、停留更长；适合结果、安心和温和收束
```

不要把节奏写成毫秒、倍速或 Provider 参数。

## emotion

选择最具体的主要状态：

```text
基础/正向：平静、放松、安心、高兴、兴奋、自信
认知状态：疑惑、怀疑、犹豫、惊讶
轻度负向：担心、心烦、烦躁、不耐烦、无奈、失望、挫败、伤心
强度负向：焦虑、紧张、害怕、慌张、愤怒、暴躁
```

容易混淆的边界：

```text
平静  本来就稳定
放松  身体或精神状态松弛
安心  原本有顾虑，现已确认风险较低

疑惑  没理解原因
怀疑  不相信现有判断
犹豫  不确定是否采取行动

担心  轻度关切
焦虑  反复确认、拿不准
紧张  面临即时结果时绷紧
害怕  明确恐惧
慌张  强烈且急迫的失序

心烦    抱怨、纠结
烦躁    明显不爽
不耐烦  失去等待或反复处理的耐心
愤怒    明确生气但仍可控
暴躁    更强、更容易爆发

无奈  接受当前无解或难办
失望  期待落空
挫败  努力后仍失败
伤心  情绪性难过
```

一个 Shot 的 emotion 描述该 Shot 已处于的状态。`焦虑 → 安心` 这类转变优先拆成多个 Shot，由中间事实/产品结果建立因果。

## stance

对听众的表达姿态，不是人物心情：

```text
默认 / 安抚 / 鼓励 / 共情
```

大多数 Shot 用默认。只有旁白或角色明确在安抚、鼓励、理解对方时使用。

## expression

表达方式，不是心情：

```text
默认 / 低声 / 耳语 / 喊叫 / 玩笑 / 秘密感
```

大多数 Shot 用默认。不要为了使用模型能力而滥加 expression。

## 视听一致性

- `speech.text` 的语义必须与 emotion 一致。
- Wan 的人物表演应由具体眉眼、视线、手部和身体动作实现，不只写抽象情绪词。
- 植物 Shot 的 emotion 只服务旁白；不得让 Wan 通过“焦虑氛围”加重黄叶或虫害。
- 同一 Scene 的情绪演进应有原因，不随机来回切换。
